# 3. 経済被害額の推計（治水経済調査マニュアル準拠）

実装: `rri_sim/damage.py`, `rri_sim/assets.py`, `rri_sim/data/estat.py`

## 3.1 算定式

$$\text{被害額} = \sum_{\text{資産}} \text{資産額}(\text{メッシュ}) \times \text{被害率}(\text{浸水深}[,\ \text{地盤勾配},\ \text{浸水日数}])$$

| 資産 | 基礎数量（データ） | 評価単価（R7.6改正・令和5年評価額） | 被害率 |
|---|---|---|---|
| 家屋 | 延床面積 | 都道府県別 家屋1m²当たり（第1表） | 表-4.2（地盤勾配A/B/C群別） |
| 家庭用品（自動車除く） | 一般世帯数（国勢調査 R2, 250 mメッシュ T001142） | 9,368千円/世帯（第2表） | 表-4.3.1 |
| 自動車 | 一般世帯数 | 3,502千円/世帯（第2表） | 表-4.3.2（地盤面からの浸水深） |
| 事業所償却・在庫 | 産業大分類別従業者数（経済センサス 500 mメッシュ T001147） | 第3表（大分類） | 表-4.4 |
| 農漁家償却・在庫 | 総農家数（2020年農林業センサス 1 kmメッシュ T001079、農地面積で按分。漁家は含まない） | 第4表 | 表-4.5 |
| 水稲 | 水田面積（L03-b） | 平年収量（第5表）×米価187千円/t（第6表） | 表-4.6（浸水深×**浸水日数**） |
| 畑作物 | 畑面積（L03-b、樹園地・牧草地を含む） | 都道府県の平均評価額 c [千円/a]（下記） | 表-4.6 畑平均（浸水日数） |

畑作物の評価額 c は、令和2年の (耕種 − 米) 農業産出額 ÷ 畑耕地面積 とした
（生産農業所得統計 都道府県別農業産出額 e-Stat 000032183954、耕地及び作付面積統計 田畑別耕地面積 000032060248）:
福岡 79.5、佐賀 73.4、熊本 43.5、大分 37.0、福島 22.3、宮城 17.2 千円/a（`damage.FIELD_VALUE_KYEN_PER_A`）。
野菜・果樹・花き・工芸作物を含む平均で、施設園芸の多い地域では露地畑の被害を過大に、施設被害は過小に見積もる。

浸水日数: 毎時の浸水深スナップショットで浸水深 ≥ 0.1 m の時間数 ÷ 24（GUIの計算、評価期間内）。

## 3.2 実装上の解釈・仮定（要レビュー）

1. **床上浸水深の基準**: マニュアルは「メッシュ水深45 cm以上を床上」とするため、床上の区分
   （50 cm未満, 50–99, 100–199, 200–299, 300 cm以上）は**床面からの浸水深** $d_f = h - 0.45$ に適用した。
   地盤面からの浸水深と解釈する実務例もあるため、`floor_height` 引数で変更可能。
2. **延床面積**: マニュアルは JACIC 100 mメッシュ（有償）を推奨。代替として
   世帯数×1住宅当たり延べ面積（住宅・土地統計調査H30）＋従業者数×30 m²（仮定）で推計。
3. **1 kmメッシュ→計算メッシュ按分**: マニュアル4.2(3)に従い宅地（建物用地）面積比で按分。
4. **地盤勾配**: DEM勾配を3×3セルで平滑化（マニュアル4.3.1(1)2) の「より広い範囲で平均」に対応）。
5. **階数補正 γ**: 平均階数データがあれば適用（f<3: 1, f≥3: 2/f）。現状は未整備のため γ=1。
6. **土砂堆積の被害率**: 表は保持しているが、土砂輸送モデルがないため適用しない。
7. **農漁家世帯数**: 2020年農林業センサスの総農家数（1 kmメッシュ）で代替。漁家は含まない。
8. **浸水域の判定**: 斜面の薄層流（地表流）を浸水と区別するため、HAND（最寄り河道からの比高）≤10 m かつ
   最大浸水深 ≥ 0.1 m のセルのみを被害算定対象とする（`basin.floodplain_inundation`）。

9. **セル内の資産の標高（サブグリッド, `rri_sim/subgrid.py`）**: 計算格子は1セル1標高のため、
   従来はセル内の全資産を同じ浸水深で浸水させていた（1 km格子では盆地の町全体が谷底の水深で浸水）。
   各セル内の100 m土地利用メッシュ（L03-b）の地盤高を5 m標高（DEM5A、欠測はDEM10B）から求め、
   建物用地（0700）・農地（0100/0200）・全メッシュの標高分布（20分位）をセルの標高との差として保持する。
   セルの水量（水深 h × セル面積）を全メッシュの標高分布に入れたときの水位 H を求め（谷のセルでは低い部分に水が集まる）、
   各メッシュを H − 地盤高 の深さで浸水させる。家屋・家庭用品・自動車・事業所・農家資産は建物用地の分布、
   農作物は農地の分布、浸水面積は全メッシュの分布を用いる。床上・床下世帯数も同様。メッシュのないセルは従来どおり。
   GUIの既定（`params={"subgrid": False}` で従来法）。初回に5 m標高タイルを取得（筑後川全域で数分）。

### 水害統計との比較（`scripts/validate_damage.py`）
水害統計調査 令和2年「表-3 市区町村別水害被害」（e-Stat 000032217685、`rri_sim/data/suigai.py`）と、
市町村界（国土数値情報 N03 2020、`rri_sim/data/admin.py`）でモデルを市町村別に集計して比較した。
水害統計は市町村全体・その年のすべての水害の値なので、流域内の面積が50%以上の市町村の合計で比べる。
表の値は「従来（一律）→ セル内標高 / 水害統計」。

| ケース | 床上世帯 | 床下世帯 | 浸水面積 km² | 一般資産 億円 | 農作物 億円 |
|---|---|---|---|---|---|
| 玖珠川 1000 m（玖珠町・九重町） | 393 → 248 / 112 | 2,252 → 77 / 118 | 23.0 → 3.0 / 0.5 | 155 → 97 / 37 | 2.2 → 0.7 / 45.0 |
| 玖珠川 250 m（同） | 767 → 697 / 112 | 1,141 → 406 / 118 | 15.2 → 7.2 / 0.5 | 253 → 201 / 37 | 2.8 → 1.7 / 45.0 |
| 筑後川全域 1000 m（26市町村） | 62,931 → 53,058 / 686 | 49,095 → 12,107 / 1,364 | 432 → 219 / 78 | 15,653 → 13,151 / 302 | 125 → 81 / 71 |

読み取り:
- セル内標高で床下・浸水面積の過大は大きく減る（1 kmの山間部で特に）。それでも床上世帯・一般資産は
  玖珠川で2〜6倍、筑後川全域で数十倍の過大。**残る過大は被害算定ではなく浸水域（水理）の過大**による。
- 玖珠川: 小ヶ瀬のピーク流量は観測より小さい（250 m 3,112 / 1000 m 3,654、観測 3,982 m³/s）のに、
  玖珠町の玖珠川本川（集水面積300〜370 km²）沿いで越水する。河道断面（面積–幅・深さの回帰式, 幅約76 m・深さ約3 m）と
  堤防（玖珠川モデルは既設堤防を推定していない。DEM5A推定を試すと大半の河道が「谷」と判定され 床上 738→581 にとどまる）
  が実際の流下能力を下回っている。
- 筑後川全域: 過大の大半は佐賀平野・筑後川下流の低平地（佐賀市 28,090 / 0、神埼市 4,151 / 1、みやき町 3,417 / 0、
  久留米市 9,562 / 365 世帯）。平地ではセル内の標高差が小さく、サブグリッドは効かない。docs/04 の
  感潮区間の堤防天端・クリーク・排水機場の表現不足と整合する。2020年の久留米市の被害は全額「内水」（表-25）。
- 農作物: 九重町の農作物被害 44.6億円（農地の浸水面積 0.29 km²）は浸水による作物被害だけでは説明できず
  （施設・ハウス等の可能性）、モデルでは再現できない。市町村によっては数十倍の差がある。
- 次の課題: 河道断面・堤防（定期横断測量・堤防台帳）、低平地の排水（排水機場・クリーク）、2012年・2017年など別イベントでの照合。
