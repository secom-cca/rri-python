# 11. Dynamic Adaptive Policy Pathways（DAPP）

実装: `rri_sim/dapp/`（config, model, run; Robust DAPP は robust, landuse, 11.9; Multi-Actor Robust DAPP は multi, actors, 11.10）、実行: `scripts/run_dapp.py`、表示: GUI `http://127.0.0.1:8765/dapp`、
テスト: `tests/test_dapp.py`。気候変動に応じて治水施策を段階的に導入・変更する適応経路（戦略）を、
2020〜2100年について比較する。施策の候補・評価器（RRI＋被害額・事業費・指標）・効用・Regret は RDM（docs/09）を再利用し、
RRI の物理計算は変更しない。

## 11.1 実行手順

```bash
.venv/bin/python scripts/run_dapp.py --quick                     # 4戦略 × 3気候経路（阿武隈川全域 1000 m）
.venv/bin/python scripts/run_dapp.py --print-default > my_dapp.json
.venv/bin/python scripts/run_dapp.py --config my_dapp.json        # 全6戦略・設定変更
.venv/bin/python scripts/run_dapp.py --robust                    # Robust DAPP（代理モデル, 約2分, 11.9）
.venv/bin/python scripts/run_dapp.py --robust --verify 6         # その代表的な経路の状態を RRI で確認
.venv/bin/python scripts/run_dapp.py --multi                     # Multi-Actor Robust DAPP（国・上流・下流自治体, 約5分, 11.10）
.venv/bin/python scripts/run_dapp.py --multi --single            # 同じ枠組みで単一主体（流域, 全施策; 約1分）
.venv/bin/python scripts/run_dapp.py --multi --verify 4          # 個別最適の経路の状態を RRI で確認
.venv/bin/python -m rri_sim.gui                                   # → http://127.0.0.1:8765/dapp
```

結果は `data/processed/dapp/<name>/`（`config.json`＝全設定、`evaluations.jsonl`＝RRI のキャッシュ、`results.json`）。
同じ施策の組合せ・気候の計算はキャッシュから再利用する（戦略間・気候経路間で共通の期が多い）。

## 11.2 時間と気候

- 2020〜2100年、10年ごとに意思決定（8期）。期 y〜y+9 は中央年 y+5 の気候で代表する。
- 気候経路（`climate_paths`）: 年・降雨倍率・海面上昇の折れ線。既定は現在気候（一定）、2℃（2100年 ×1.10・0.38 m）、
  4℃（2100年 ×1.20・0.70 m）。2100年値は国交省提言・日本の気候変動2020（根拠）、途中の経路は仮定。
- **近似（重要）**: 各10年を**代表洪水1回**（流域のイベント＝阿武隈川では2019年台風19号、その期の気候で降雨を拡大し海面を上げる）で代表し、
  **年超過確率 p（既定 1/100, 仮定）**を掛けて期待被害とする（各年の期待被害 = p × 代表洪水の被害額）。
  - 洪水の頻度分布（大小さまざまな洪水）、年々の変動、複数洪水の連続、気候変動による頻度の変化は表さない
    （気候変動は「同じ確率の洪水が大きくなる」として扱う）。
  - 被害の絶対値は p と代表洪水の選び方に強く依存する。戦略間の**相対比較**として用いる。
  - 代表洪水は1つの降雨パターンなので、施策の効果（特に田んぼダム・遊水地）は他の降雨では異なりうる。

## 11.3 施策と実施（`measures`）

RDM の候補施策（地域別の堤防・遊水地・田んぼダム・森林化・住宅対策）を、`"type[@zone]:option"` で指定する
（例 `levee:1`＝全地域の堤防 +1 m、`relocate@下流:2`＝下流の移転）。施策の種類ごとに:

| 項目 | 堤防 | 遊水地 | 田んぼダム | 森林化 | 嵩上げ | 移転 |
|---|---|---|---|---|---|---|
| 着手〜完成（年） | 10 | 10 | 0 | 0 | 5 | 10 |
| 効果の発現 | 完成時 | 完成時 | 即時 | 30年で 0→1 | 完成時 | 完成時 |
| 変更時の費用（既存の初期費用に対する割合） | 0.2 | 0.2 | 0 | 0 | 0.5 | 0.2 |

（すべて仮定、設定ファイルで変更可）。期の中央年までに完成した施策がその期に効く。事業費は `costs.py` の初期費用
（着手年に計上）と維持費（完成後毎年）で、割引率（既定 4%）で2020年に割り引く。より高い選択肢への変更（堤防 +1→+2 m、
嵩上げ→移転）は初期費用の差額＋変更費用。予算: 初期費用の総額上限と10年ごとの上限（戦略ごとに倍率 `budget_cap_factor`）。
上限を超える施策は次の期に繰り越す。

## 11.4 戦略（`strategies`）

| 戦略 | 内容（既定） |
|---|---|
| 無対策 | なし |
| 早期集中投資 | 2020年に堤防 +1 m・遊水地・田んぼダム・下流の嵩上げ（10年上限 ×4） |
| 段階的投資 | 10年ごとに田んぼダム→堤防 +1→遊水地→下流嵩上げ→堤防 +2 |
| 自然基盤重視 | 田んぼダム・森林化→遊水地→下流の移転 |
| 構造物重視 | 堤防 +1→遊水地→堤防 +2 |
| 状況適応型 | 田んぼダム・森林化から始め、**観測指標**（1期前の代表洪水の被害額・浸水人口 ÷ 対策なし現在気候）が `trigger_ratio` を超えたら経路の次の施策（堤防 +1→遊水地→下流嵩上げ→堤防 +2→移転）を着手。実施遅延・予算上限を反映 |

## 11.5 適応転換点（ATP）と評価

- ATP: 代表洪水の被害額または浸水人口が「対策なし・現在気候 × 閾値（既定 1.2）」を初めて超える期。
  予算: 予算不足で施策が繰り越された最初の年。意思決定者ごとに、その地域の被害額と各自の閾値（`stakeholder_atp_ratio`）でも求める。
- 指標: 累積期待被害（PV）、累積事業費（PV）、Livability・Ecology・浸水人口の期間平均。
- Regret: RDM と同じ効用（地域・重み）を累積・平均の指標で計算し、各気候経路で最良の戦略との差。最大・平均 Regret、
  許容閾値達成率（Regret ≤ 閾値 かつ その意思決定者の ATP に 2100年まで達しない気候経路の割合）、Minimax Regret 推奨戦略。
- 感度: 各意思決定者の指標上で重みを一様に抽出したときの推奨戦略の頻度、ATP 閾値（1.0〜1.8）と到達年の関係。

## 11.6 GUI（/dapp）

Pathways Map（行＝施策、線＝戦略、○着手・│完成・✕ATP）、施策実施タイムライン（実施遅延・効果発現・切替・繰越）、
指標の時系列、ATP 到達時期、許容閾値と ATP 到達年、戦略別スコアカード、意思決定者ごとの Regret、重みと推奨戦略、
意思決定者別の ATP。

## 11.7 試行結果（`--quick`: 4戦略 × 3気候経路, 阿武隈川全域 1000 m）

RRI 74 回・46 分（`data/processed/dapp/abukuma_dapp_quick/`）。累積値は2020年への現在価値（億円）。

| 戦略 | 累積期待被害 現在 / 2℃ / 4℃ | 累積事業費 | ATP（4℃） |
|---|---|---|---|
| 無対策 | 188 / 199 / 215 | 0 | 被害 2050・浸水人口 2040（2℃でも人口 2040） |
| 早期集中投資 | 108 / 132 / 142 | 1,161 | 被害 2080・人口 2070 |
| 段階的投資 | 113 / 133 / 146 | 705 | 被害 2080・人口 2070・予算 2030（繰越） |
| 状況適応型 | 115 / 136 / 152 | 825（4℃ 885） | 被害 2080・人口 2070・予算 2080 |

- **Minimax Regret: 段階的投資**（国・上流自治体）。下流自治体は状況適応型、住民は早期集中投資（浸水世帯の重み 0.6 のため）。
  重みをランダムに変えると、国は無対策 45%・状況適応型 32%・段階的 21%、下流自治体は状況適応型 81%、住民は早期集中 100%。
- 状況適応型は現在気候・2℃では引き金が引かれず（田んぼダム・森林化のみ）、4℃で 2070年代の浸水人口の急増（2.35倍）を
  1期遅れで観測して 2080年に堤防、2090年に遊水地を着手（10年上限で一部繰越）。完成が 2090〜2100年となり ATP は回避できない
  → 引き金を早める（`trigger_ratio` を下げる、`monitor_lag` 0）か、気候の観測（降雨倍率）を指標にする検討が必要。
- 状況適応型の事業費のうち約 600 億円は森林化による作物収入の損失（維持費として計上, costs.py）。初期費用は 222 億円。
- 浸水人口は 1000 m では階段状（docs/10 10.5）で、ATP の判定がこの跳びに左右される。

## 11.8 限界

- 11.2 の代表洪水の近似。阿武隈川全域モデルは未校正で流量が過小（docs/04）、1000 m は粗い（docs/08）。
- 施策の劣化・更新、土地利用・人口の将来変化、社会経済シナリオは考慮していない（資産・人口は2020年のまま）。
- 状況適応型の観測は完全（モデルの値をそのまま観測とみなす）で、観測の遅れは `monitor_lag` 期のみ。
- 森林化の効果係数は全森林化地域で共通（平均の経過年数）。

## 11.9 Robust DAPP（深い不確実性下の頑健な初期施策と分岐する適応経路）

実装: `rri_sim/dapp/robust.py`（ステップ 1・3–5）、`rri_sim/dapp/landuse.py`（ステップ 2）、設定: `rri_sim/dapp/config.py` の `robust`、
実行: `scripts/run_dapp.py --robust [--quick] [--verify 6]`、表示: GUI `/dapp`（実行名 `abukuma_dapp_robust`）、テスト: `tests/test_dapp.py`。

11.1〜11.7 の DAPP は、あらかじめ決めた6戦略を3つの気候経路で比べる。Robust DAPP は、**単一の最適計画ではなく**
「今実施すべき初期施策」「どの条件で、どの施策へ分岐するか」「対応できない将来」を、多数の将来シナリオの上で探す。
RRI の物理計算は変更せず、計算は探索（docs/12）の代理モデル上で行う。（この節の設計は Pareto 解＝施策の組合せを経路のノードにする。個別施策を経路の単位にし、条件付き適応戦略を探索する設計と、その複数主体への拡張は 11.10。比較のためこの節の実行も残す。）既存の機能は再実装せず共通化した:

| 使うもの | 共通化した既存機能 |
|---|---|
| 代理モデル・事業費 | docs/13 の `roadmap.physics.SurrogatePhysics`（探索 `abukuma_explore_v2` の GP、費用表 `cost_parts.json`） |
| 施策候補の探索 | docs/12 の `explore.nsga_mixed`（NSGA-II）と探索の Pareto 解（初期集団）、`explore_scope.nondominated` |
| 将来シナリオ | docs/13 の `roadmap.world`（気候・社会経済・施策効果・実施期間の因子） |
| 実施状態・時間管理 | docs/13 の `roadmap.sim.State`（合意→施工／普及→成熟、予算と繰越、変更費用、維持費、観測 `observe`） |
| 評価 | `sim.score`（効用・費用 PV）、`metrics.prim_box`（PRIM）、代表洪水の近似（11.2） |

`sim.State` には、可逆な施策の縮小と若い森林の農地への再転換（Robust DAPP だけで有効: `allow_decrease`）を追加した。
docs/13 の挙動は変わらない（テストで確認）。

### 11.9.1 5つのステップ

1. **施策候補の探索**（重みなし）: 施策の水準（docs/13 の `levels`: 堤防 0/+1/+2 m、田んぼダム・森林化・各戸貯留 0/50/100% など 22 変数）を遺伝子とし、
   代理モデル上の NSGA-II で 費用（PV）・目標達成率（シナリオのうち `candidates.eval_years` に目標を満たす割合）・被害額の比・Ecology・Livability の
   非劣解を求める。初期集団に探索（docs/12）の Pareto 解を使う。最初の10年の予算で始められる組合せ（初期費用 ≤ `initial.max_cost_oku`）についても同じ探索をする。
2. **施策間の移行可能性**（`landuse.Transitions`）: 施策の**実施状態**（何を・どの水準で）と**土地利用**（地域ごとの農地・転換した森林・遊水地・浸水域の住宅地・移転跡地）を別に持つ。
   - 水準を上げる移行はいつでも可。費用＝初期費用の増分＋`change_cost_fraction` × 置き換える選択肢の初期費用（嵩上げ→移転など）。期間は docs/13 の合意＋施工／普及（＋森林は成熟の半分）。予算（総額・10年ごと）を超える分は次の期へ繰越。
   - 下げる移行は `reversible` な施策（田んぼダム・各戸貯留）だけ。森林は植栽後 `reconvert.max_age_years`（10年, 仮定）以内なら植栽費の 50% で農地に戻せる（条件付き: 経路の上で植栽年を見て判定）。
     遊水地（農地→遊水地）と移転（住宅地→移転跡地）は戻さない。移転→嵩上げは不可。
   - 土地の整合: 森林化した水田では田んぼダムができない（`forest_on_paddy_share`, 仮定 0.5）。
   - ノード＝選んだ非劣解（全体・初期の各 24）、施策なし、それらの和集合（変数ごとに高い方の水準; 別の組合せの施策を後から足せるように）。最大 400。
   - 経路の選択肢: 各ノードから、より頑健な（名目の仮定で目標を満たせなくなる降雨倍率が高い）移行先のうち、移行費用と頑健さで非劣なものを最大 `network.max_successors`（4）。
3. **ATP とトリガー**: 各ノードについて、シナリオごとに、その組合せが完成・成熟した状態で目標（`targets`: 2030年以降の各期の代表洪水で 被害額 ≤ 1.2 ×、
   浸水人口 ≤ 1.5 × 対策なし・現在気候, 仮定）を初めて満たさなくなる期（ATP）。トリガーは**観測できる情報だけ**で決める:
   直前の期の被害の比（観測誤差あり）が ρ × 目標を超えた、または観測した降雨・海面・浸水域の資産と人口の傾向から、**次の移行の完成（リードタイム）＋1期 までに**
   現在の組合せが ρ × 目標を超えると予測された（`trigger`: ρ＝0.9, 仮定）。
4. **適応経路の生成**（Pathways Network）: 全初期施策 × 全シナリオについて、2020〜2100年を10年ごとに、トリガーが引かれたら経路の選択肢のうち
   「完成後 `horizon_years`（30年）先まで目標を満たすと予測される最も安い移行先」へ移る（なければ予測が最もよい移行先へ、"移行先の不足" として記録）。
   予測は観測した傾向と計画時の仮定（効果係数・γ は名目）による。**完全情報ベンチマーク**は同じ規則でシナリオの真の結果と真のリードタイムを使い、
   2100年までを見通す（貪欲法の近似）。比較用にだけ使う。
5. **頑健な初期施策の評価**: 初期施策ごとに
   - カバー率: 観測に基づく経路で全期間目標を満たしたシナリオの割合（完全情報のカバー率も併記）。**不確実性のサンプル（LHS）の割合で、発生確率ではない**。
   - Regret: 効用（`weights`, 既定は docs/13 の現行の重み・閾値＝目標）の、そのシナリオの全経路（観測・完全情報）の最良との差。最大・平均・90%値。
   - 累積費用（PV、初期・維持・変更・再転換）。
   - Lock-in: (a) 選択肢: 施策なしから到達できる有用な組合せ（あるシナリオで 2100年まで目標を満たす）y について、この初期施策 i から y の施策を足した組合せ
     （土地に合わせて調整）に予算内で到達できない、または y の施策が土地利用で置けなくなる割合（あわせて上乗せ費用）、
     (b) シナリオ: 施策なしから始めれば完全情報で対応できたが i からは対応できない割合、(c) 不可逆な初期費用・転換した土地。
   - 有望＝カバー率・最大 Regret・平均費用・Lock-in（選択肢）で非劣。
   どの経路でも目標を満たせないシナリオ（**対応できない将来**）は PRIM で範囲を示す。

- **今実施すべき初期施策**: 有望（非劣）は 8 案＋施策なし。#2（250 億円）はカバー率が完全情報の 9 割に達し、費用は #73 より 190 億円安い。
  #73 は最大 Regret が最小。いずれも Lock-in はない（後から堤防・遊水地を足せる）。施策なしは安いがカバー率・Regret が最も悪い。
- **どの条件で、どの施策へ分岐するか**（#2 の場合）: 17 シナリオでは移行不要（全て達成）。82 シナリオ（2030〜2070年、中央値 2050年、観測した降雨倍率 1.02〜1.15）で
  堤防 中流・下流 +2 m・上流の移転への切替・公共貯留など（＋448 億円）へ移り、うち 56 シナリオは 2040〜2090年に遊水地2・3・上流堤防・排水機場など（＋1,073 億円）へ進む。
  24 シナリオは別の枝（堤防・中流 +1 m 系）へ進む。
- **対応できない将来**: 観測に基づくどの経路でも目標を満たせないシナリオは 47 / 128（完全情報でも 46）。PRIM: 2100年の降雨倍率 ≥ 1.16 かつ γ ≥ 0.93
  （範囲内の該当 81%、該当シナリオの 89% が範囲内）。予算（総額 2,000 億円）と施策の上限では、4℃相当以上の降雨増には目標を保てない。
- **Lock-in**: 森林化を含む早い初期施策（#24 など）は、森林化した水田で田んぼダムが置けなくなり、植栽後 10 年を過ぎると戻せないため、選択肢 17%・シナリオ 16% を失う。
- **RRI による確認**（`--verify 6`）: #73 の代表的な経路（2100年の降雨が最小・中央・最大のシナリオ、最初の移行後と最終期）の 6 状態を RRI で再計算。
  被害額 435〜1,273 億円に対し R² 0.98・相対 RMSE 5.0%（差 −6〜+5%）。
- 観測に基づく経路と完全情報の差（カバー率 3〜9 ポイント）は、観測の遅れ・誤差と、効果係数や強雨強調 γ が観測できないことによる。

### 11.9.4 限界

- 代理モデルの精度・学習範囲（docs/12 12.9）。範囲外の気候・効果係数は切り詰める（外挿しない）。ノードは完成・成熟した状態の ATP、経路は施工・成熟の途中を含めて評価する。
- 代表洪水1回の近似（11.2）。浸水人口は階段状（docs/10 10.5）で、浸水人口の目標の判定がこれに左右される。
- 社会・参加の過程（合意の失敗・参加率・調整費用, docs/13）は扱わない（合意期間はリードタイムに含める）。強雨強調 γ は docs/13 と同じく期間中一定。
- 完全情報ベンチマークは貪欲法の近似で、真の最適経路ではない（観測に基づく経路が上回るシナリオもある）。
- ノードは非劣解と和集合に限るため、経路はその中でしか選べない。移行先の選び方（最安で見通しを満たす）とトリガー ρ は仮定で、GUI の設定パネルで感度を見る。

## 11.10 Multi-Actor Robust DAPP（個別施策の条件付き適応戦略と主体間の相互依存）

実装: `rri_sim/dapp/actors.py`（主体・行動・戦略・外生ルール・制御）、`rri_sim/dapp/multi.py`（模擬・探索・比較・経路・ネットワーク）、
設定: `rri_sim/dapp/config.py` の `multi`（モデル・土地利用・シナリオ・流域の目標・PRIM は `robust` を共有し `robust_overrides` で上書き）、
実行: `scripts/run_dapp.py --multi [--single] [--quick] [--verify 4]`、表示: GUI `/dapp`（実行名 `abukuma_dapp_multi`／`abukuma_dapp_single`）、
テスト: `tests/test_dapp.py`。

### 11.10.1 Pathways Map の再設計（11.9 との違い）

| | 11.9 Robust DAPP | 11.10 |
|---|---|---|
| 経路の単位（Map の縦軸） | 施策の組合せ（Pareto 解とその和集合） | **個別施策の行動**（追加・強化・縮小・変更・再転換） |
| 状態 | ノード（組合せ）| 各施策の実施水準・実施中の事業（合意→施工／普及→成熟）・主体ごとの予算の使用額・土地利用（`sim.State`, `landuse.Transitions`） |
| 状態遷移 | ノード間の移行（行列） | 行動 1 つずつ。移行費用・リードタイム・不可逆性・土地利用・予算は `sim.State` がその場で判定（不可能な行動は飛ばし、予算超過は繰越） |
| 最適化の対象 | 静的な組合せ（＋貪欲な移行規則） | **条件付き適応戦略**（観測に応じて次の行動を変える規則）を NSGA-II で探索 |
| Pareto 解の役割 | 経路のノード | 戦略の探索の初期値（`pareto_seeds`）だけ |
| 評価 | ノードの ATP・初期施策ごと | 経路全体（カバー率・Regret・累積費用・Lock-in・将来の選択肢）。途中で一時的に劣る状態も、経路全体で良ければ残る（状態の枝刈りをしない） |

**行動**（`actors.make_actors`）: 主体の施策ごとに、各水準への引き上げ（例 堤防 +1 m、+2 m、嵩上げ、移転＝嵩上げからの変更）と、
可逆な施策（田んぼダム・各戸貯留）の縮小、若い森林の農地への再転換（11.9 と同じ条件）。森林化した水田の田んぼダムは土地に合わせて自動で下げる。

**条件付き適応戦略**（`actors.Strategy`）:

- 初期施策（2020年に着手する各施策の水準）
- 経路 A（基本）と経路 B（厳しい気候）: それぞれ最大 `strategy.seq_len`（4）個の行動の順序
- 分岐: 観測した降雨倍率の傾向から予測した2100年の降雨倍率が `switch` 以上になったら、以後は経路 B（切替は1度だけ＝分岐点）
- トリガー: その主体の指標の観測値（直前の期、誤差あり）÷ 目標 が ρ を超えた、または（`anticipate`）現在の状態のままだと、次の行動の完成（リードタイム）＋1期 後に
  ρ を超えると予測された（観測した気候・資産・人口の傾向, 代理モデル, 名目の効果係数）ら、有効な経路の次の行動に着手する。経路 B への切替も着手の契機になる。

戦略は整数の遺伝子（初期水準・A・B・switch・ρ・anticipate）で表し、`explore.nsga_mixed` で探索する。
**分岐の判断材料の情報量**: 観測した降雨の傾向から予測した2100年値と真の値の相関は、2030〜2050年は 0.1 前後、2060年 0.56、2070年 0.79、2080年 0.93
（`signal_quality`, GUI）。それ以前の切替は雑音で起きるため、切替は `strategy.switch_from_year`（2050年, 仮定）以降に限る。

### 11.10.2 主体と他主体の意思決定の不確実性

| 主体 | 施策（小規模モデル） | 予算（総額／10年, 仮定） | 指標・目標（ATP・トリガー） | 効用の重み（Regret） |
|---|---|---|---|---|
| 国（河川管理者） | 堤防 上流・下流、遊水地1・2 | 1,000 / 400 億円＋移転の補助 | 流域の被害額 ≤ 1.2×・浸水人口 ≤ 1.5× | 被害・浸水人口・費用・Ecology・農業 |
| 上流自治体 | 田んぼダム・森林化・住宅対策・公共貯留（上流） | 300 / 120 億円 | 上流の被害額 ≤ 1.2× | 被害・費用・Ecology・農業 |
| 下流自治体 | 田んぼダム・住宅対策・排水ポンプ・公共貯留（下流） | 600 / 250 億円 | 下流の被害額 ≤ 1.2× | 被害・費用 |

- 予算は `sim.State` の主体ごとの上限（`budgets`, `payer`）。移転・嵩上げは国が半分を負担（`multi.subsidy`, 仮定）。費用は施策ごとに記録し負担割合で主体に配分する。
- 地域の被害額は代理モデルの地域別出力（`dz:上流`, `dz:下流`）。地域別の浸水人口は代理モデルにないため、自治体の目標は被害額のみ。
- **他主体の外生ルール**（`multi.rules`）: 積極投資（全施策を最初に着手、予算超過分は繰越）、段階投資（費用対効果の順に、観測・予測が 0.9 × 目標を超えるたび1つ）、
  投資抑制（観測が 1.3 × 目標を超えるまで何もしない、以後リードタイムの短い順に1つずつ）。どれも同じ戦略の形で表す。
- **主体ごとの探索**: 各探索シナリオ（気候・社会経済・施策効果・実施期間の LHS）に他主体のルールの組合せ（3² 通り）を順に割り当て、
  主体の戦略を NSGA-II で探索する（目的: カバー率・自分の費用・自分の効用・Lock-in; 重みなし）。推奨＝最高カバー率から `choose.coverage_tolerance`（3 pt）以内で最も安い戦略。
- **流域全体の探索**: 全主体の戦略をつないだ遺伝子で NSGA-II（目的: 全主体の目標を同時に満たす割合・総費用・流域の効用・平均 Lock-in）。
- **比較**: 探索に使っていない評価シナリオ（64）で、個別最適の組合せ・流域全体の最適・外生ルールの全組合せ（3³＝27）を模擬し、
  主体別・流域全体のカバー率・Regret（各主体の効用の、そのシナリオのすべての構成の最良との差）・費用・Lock-in（2060年に土地利用・不可逆性・予算で実行できなくなった行動の割合）・
  将来の選択肢（2060年にまだ実行できる行動の割合）を求める。**Robustness Gap**＝流域全体の最適 − 個別最適の、全主体の目標を満たす割合の差。主体ごとには、流域全体の最適のために
  下がる（上がる）自分のカバー率と費用。
- 他主体の行動への依存: 各主体の推奨戦略を固定し、他主体がルールの各組合せに従ったときのカバー率・初回の着手年。施策の波及: 各主体の施策だけを実施したときの各主体の指標。

**ゲーム理論への拡張**（実装済みの部品）: `multi.best_response(ctx, actor, scen, others, ...)` は、`others` にシナリオごとの他主体の戦略を渡す最適応答である。
いまは外生ルールの混合を渡しているが、他主体の推奨戦略を固定して渡し主体を順に回せば Best Response 反復（Nash 均衡の探索）になる。
国の補助率 `multi.subsidy` は予算・費用の負担に効くので、国を先手としてこれを変数にすれば Stackelberg ゲームになる。均衡計算は未実装。

  流域全体で選ぶと 58%（総費用は ＋27 億円）。流域の最適では、国が 堤防・下流 +2 m を最初に着手し、2050年以降に降雨の傾向が ×1.16 を超えたら 堤防・上流 +2 m・遊水地2 へ、

  田んぼダムと移転に頼る（48%）。下流の目標は国の堤防の有無に強く依存する（施策の波及: 国の施策で下流の指標 1.16→1.08）。

### 11.10.5 限界

- 小規模モデル（主体3・各4施策・評価 64 シナリオ）。主体・施策・シナリオは設定で増やせる（`multi.actors`, `robust_overrides`, `search`）。探索は NSGA-II の
  有限の世代で、推奨戦略は探索シナリオ（27）上の選択（評価シナリオでは成績が変わりうる）。
- 戦略の形（経路 A／B の2本・切替1回・1期に1行動）は仮定。分岐の判断材料は降雨の傾向だけ（被害の観測はトリガーに使う）。
- 自治体の目標は地域の被害額だけ（地域別の浸水人口は代理モデルにない）。他主体の行動は3つの外生ルールで、主体間の交渉・補助の配分の決定（ゲーム）は扱わない。
- 代理モデル・代表洪水1回の近似・社会過程を扱わないことは 11.9.4 と同じ。
