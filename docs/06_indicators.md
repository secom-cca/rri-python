# 6. 評価指標（Livability / Ecology / 安全・安心）と事業費

実装: `rri_sim/indicators.py`, `rri_sim/costs.py`, データ: `rri_sim/data/facilities.py`, `estat.py`, `landuse.py`

施策ごとに **洪水被害額** に加えて、以下を現況と比較する（GUIの「指標」「被害・費用」タブ）。
すべての小指標は 0〜1 に正規化し、スコアは 100 × 平均。パラメータは結果に同梱して出力する。

## 6.1 Livability Score（生活利便性）

国土交通省「都市構造の評価に関するハンドブック」(2014) の **生活利便性** 分野の指標
（生活サービス施設の徒歩圏人口カバー率、利用圏平均人口密度、居住を誘導する区域の人口密度）を参考に構成した。

| 小指標 | 定義 | データ |
|---|---|---|
| 医療 | 0.5×徒歩800m圏人口カバー率 + 0.5×自動車アクセス | 国土数値情報 P04-20 医療機関（病院・診療所のうち内科／外科：ハンドブックの医療施設定義） |
| 教育 | 同上 | P29-23 学校（小学校・中学校） |
| 商業 | 同上 | 経済センサス（e-Stat T001147）卸売・小売業従業者 ≥10人のセル（※国土数値情報に商業施設がないための代理指標） |
| 公共サービス | 同上 | P05-22 市町村役場等（本庁・支所・出張所） |
| 居住集約度 | 人口加重平均密度 / 40 人/ha（DID基準）、上限1 | 2020国勢調査 4分の1メッシュ人口（T001142） |

- **徒歩圏** = 800 m（ハンドブック）。格子上の最短経路距離（水域は道路がなければ通行不可）。
- **自動車アクセス** = 人口加重平均の f(t)、f = 1（t ≤ 10分）→ 0（t ≥ 30分）で線形。走行速度は土地利用から近似した道路網
  （道路用地≥10%: 40 km/h、建物用地 30、農地 25、森林 10、水域 通行不可）。農村部の流域では徒歩圏のみでは評価が過小になるため併用した。
- 参考: ハンドブックの都市規模別平均（人口10万人以下）は 医療施設徒歩圏カバー率 57%、商業 58%、利用圏平均人口密度 9 人/ha。
  玖珠川流域（現況）は 医療 36%、商業 40%、人口加重密度 10.6 人/ha。

施策との関係: **移転**は世帯を最寄りの安全な市街地（HAND>10 m かつ現況で浸水なし）へ移すため、居住集約度・アクセスが変化する。
遊水地用地内の世帯も同じ規則で移転する。

## 6.2 安全・安心（ハンドブック「安全・安心」分野）

| 指標 | 定義 |
|---|---|
| 浸水深0.5m以上の区域の居住人口割合 | ハンドブック「防災上危険性が懸念される地域に居住する人口の割合」を本計算の最大浸水深で評価 |
| 洪水時の医療アクセス維持率 | 浸水深 ≥0.3 m のセルを自動車通行不可、浸水した医療機関を利用不可として、30分以内に到達できる人口の割合 |

## 6.3 Ecology Score（生態系）

| 小指標 | 定義 |
|---|---|
| E1 生息地の質 | InVEST Habitat Quality 型: Q = H × (1 − D^z/(D^z+k^z))。H: 土地利用別の生息適性（森林1.0、新規森林0.8、水域0.9、湿地0.85、水田・田んぼダム0.5、緑地0.6、畑0.3、建物用地0）。D: 脅威（建物用地 w=1.0・2 km、道路 w=0.7・1 km、農地 w=0.3・0.5 km）の指数減衰和。z=2.5, k=0.25 |
| E2 生態的ネットワークの連結性 | 0.5×陸域連結性 + 0.25×河川横断連結性 + 0.25×河川縦断連結性。陸域: 連結性確率指数（PC）の核近似 √(Σq·(q∗K))/√(Σ1·(1∗K))、分散距離1 km。横断: 上流域10 km²以上の河道のうち堤防（0.5 m以上）のない延長の割合。縦断: ダムを遮断とする樹状連結性指数 DCI_p（Cote et al., 2009） |
| E3 水文・生態条件 | 0.5×流域内保水率（1 − 流出量/雨量, 計算期間）+ 0.5×自然的氾濫原の冠水率（HAND≤5 m の非市街地セルのうち浸水したセルの割合＝氾濫原湿地への洪水パルス） |

施策との関係: 森林化（E1↑、E3↑）、堤防（横断連結性↓、自然的冠水↓）、遊水地（湿地化で E1↑、冠水↑）、移転跡地の緑地化（脅威↓）。
※E3の「自然的冠水」は生態系には正の効果として扱う（洪水パルス概念）。被害額とはトレードオフになる。

## 6.4 事業費（`rri_sim/costs.py`）

初期費用＋維持管理費の現在価値（評価期間50年、社会的割引率4%、年金現価係数21.48；治水経済調査マニュアルに準拠）。
**単価には仮定値を含む**（GUIの「単価設定」で変更可、カーソルで根拠表示）。

| 施策 | 数量 | 算定 |
|---|---|---|
| 堤防 | 延長（両岸）× 断面積 h(B+nh) | 盛土 8,000円/m³ + 付帯 5万円/m + 用地（敷幅×5,000円/m²） |
| 遊水地 | 面積・掘削深・越流堤延長 | 掘削運搬 1,500円/m³（掘削単価319–777円/m³の工事設計書例に運搬処分を加算）+ 用地 + 越流堤 100万円/m + 用地内世帯の移転 |
| 田んぼダム | 水田面積 | 調整板 5,000円/10a + 維持 400円/10a/年（多面的機能支払の田んぼダム加算） |
| 森林化 | 面積 | 植林 150万円/ha + 営農所得逸失（水稲 4.75 t/ha × 187千円/t × 所得率0.3）/年 |
| 移転 | 世帯・従業者 | 2,000万円/世帯（防災集団移転の事例 1,036–1,680万円/戸を物価補正）+ 300万円/従業者 |
| 嵩上げ | 世帯・高さ | 600万円/世帯/m（床高）、盛土は 5,000円/m³ |

GUIでは「本イベントの被害軽減額／事業費(PV)」を参考表示する。**これは単一イベントの値であり、
年平均被害軽減期待額に基づく正式な費用便益比（B/C）ではない**。B/C の算定には確率規模別の洪水群での計算が必要（今後の課題）。

## 6.5 玖珠川2020での例（GUI動作確認時）

田んぼダム・遊水地・堤防・嵩上げ・移転を同時に配置したケース: 被害額 304.8 → 286.2 億円（−18.7）、事業費(PV) 194.5 億円、
Livability 52.1 → 52.3、Ecology 69.0 → 68.7（堤防による河川横断連結性 −4.1 が主因）。
