# 1. モデル定式化（RRIモデル準拠）

本実装は Sayama et al. (2012, HSJ 57(2)) および RRI Technical Manual (PWRI Tech. Note 4277) に記載された
RRIモデルの物理式を参考に、Python (NumPy + Numba) で再実装したものである。
RRI公式マニュアルは ICHARM の利用規約ページ経由でのみ配布されるため、本実装では公開論文で確認できる式を用い、
確認できなかった細部は**本実装での仮定**として明記する（表1-1）。

## 1.1 斜面（2次元）

連続式（各グリッドセル）:

$$\frac{\partial h}{\partial t} + \frac{\partial q_x}{\partial x} + \frac{\partial q_y}{\partial y} = r - f$$

- $h$: 斜面貯留水深（表層土壌中の水 + 地表水）[m]、$r$: 降雨強度、$f$: 鉛直浸透（Green–Ampt）
- 水位 $H = z + h$（RRIの慣例）

流量–水深関係（RRIの側方地中流＋地表流の統合式, $i = |\partial H/\partial x|$, $k_m = k_a/\beta$）:

| 区間 | 単位幅流量 $q$ |
|---|---|
| $h \le d_m$（不飽和） | $k_m d_m (h/d_m)^\beta \, i$ |
| $d_m < h \le d_a$（飽和側方流） | $\{k_m d_m + k_a (h - d_m)\}\, i$ |
| $d_a < h$（＋地表流） | $\{k_m d_m + k_a (d_a - d_m)\}\, i + \frac{1}{n}(h-d_a)^{5/3} i^{1/2}$ |

$d_a = D\gamma_a$（土層厚×有効間隙率）、$d_m = D\gamma_m$（土層厚×不飽和間隙率）。$k_a=0$ のセルは純粋なManning地表流。

鉛直浸透（Green–Ampt）: $f = k_v\left(1 + \frac{(\phi-\theta_i) S_f}{F}\right)$。
dt内の浸透能は湛水条件の陰的積分 $k_v\Delta t = F_1 - F_0 - c\ln\frac{c+F_1}{c+F_0}$（$c=(\phi-\theta_i)S_f$）を
Newton法で解いて求める（$F\to0$ の特異性を回避し、解析解と一致: tests/test_verification.py::test_green_ampt_analytic）。

## 1.2 河道（1次元）

$$\frac{\partial A}{\partial t} + \frac{\partial Q}{\partial x} = q_L ,\qquad Q = \frac{1}{n_r} A R^{2/3} \left|\frac{\partial H}{\partial x}\right|^{1/2}\mathrm{sgn}$$

矩形断面。DEMから抽出した河道では RRI と同様に上流域面積 $A_{up}$[km²] から
$W = C_w A_{up}^{S_w}$, $D = C_D A_{up}^{S_D}$（既定 $C_w=5.0, S_w=0.35, C_D=0.95, S_D=0.2$）。
河床高は DEM のノイズによる逆勾配を除くため下流に向かって単調非増加に補正する。
下流端は等流水深（出口河床勾配）境界。逆流（背水）を許容する。

## 1.3 河道–斜面の水交換（越流公式）

同一セル内の河道水位 $H_r = z_b + h_r$ と斜面地表水位 $H_s = z + \max(h-d_a,0)$ を比較し、
天端高 $z_c = z + E$（$E$: 堤防高）を越える側から本間公式で越流させる:

- 完全越流 ($h_2 \le \frac{2}{3}h_1$): $q = 0.35\, h_1\sqrt{2gh_1}$
- もぐり越流: $q = 0.91\, h_2 \sqrt{2g(h_1-h_2)}$

（$h_1, h_2$: 高水側・低水側の天端上水深、両式は $h_2/h_1=2/3$ で連続）。
越流長は河道長×bank_factor（既定2：両岸）。交換量は、(i) 供給側が天端以下・水位均衡点を越えない、
(ii) 貯留量が負にならない、の2条件で上限を設ける。

## 1.4 数値解法

- 有限体積法（セル中心、面フラックス）。全演算子が面フラックスを両セルで共有するため**水収支は丸め誤差レベルで保存**
  （検証: 相対誤差 < 1e-12）。
- 運動量の閉じ方を2種類実装:
  - `diffusive`（RRI原法）: 上記の拡散波式。陽解法の安定条件 $\Delta t \le V_{eq}/|Q|$ から自動的にdtを決定。
    平坦地では $\Delta t\to 0$ となる（RRIが適応時間刻みRKを用いる理由）。
  - `inertial`（既定）: 局所慣性近似（Bates et al., 2010）。摩擦項を**完全陰的**に扱い
    $q^+ + \frac{g n^2 \Delta t}{h^{7/3}}|q^+|q^+ = q + g h \Delta t\, S$ を閉形式で解く。
    定常状態は拡散波のManning流量と厳密に一致し、重力波CFL条件のみで安定。
    Bates式の半陰的摩擦は大dtで2周期振動するため採用しない（V字流域で確認）。
- 正値性リミッタ: 各セルの総流出量がdt内の貯留量を超えないようフラックスを縮小（$h\ge0$ を保証）。
- 時間刻み: CFL ($c = \max(|u|+\sqrt{gh},\ \tfrac53|u|)$, Cr=0.7) と dt_max の最小。
- 降雨は区分一定強度を厳密積分するため、雨量の投入量は dt に依存しない。

### 表1-1 RRI原法との相違・本実装での仮定

| 項目 | 本実装 | 理由 / 備考 |
|---|---|---|
| 時間積分 | 前進Euler＋演算子分割（RRIは適応RKF45） | 保存性・正値性の保証を優先。dt収束性は検証済み |
| 既定スキーム | 局所慣性（拡散波はオプション） | 合成流域で拡散波との差: ピーク流量0.4%、最大浸水深RMSE 1.2 cm、計算時間1/230 |
| 斜面流向 | 4方向（D4） | RRIは8方向オプションあり。今後追加 |
| 第3領域の地中流 | $k_a(d_a-d_m)$ で飽和上限 | 物理的に土層は飽和で頭打ち |
| 越流係数 | 本間公式 (0.35/0.91) | 日本の実務標準。RRIの係数は要確認 |
| 越流長 | 河道長×2（両岸） | パラメータ化 |
| 斜面面積 | 河道セルでもセル全面積を斜面とみなす | RRIと同様の簡略化 |
| 地下水・蒸発散・ダム | 未実装 | 洪水イベント計算では二次的。ダムは段階3bで追加予定 |

## 1.5 検証テスト（合成流域）

| テスト | 内容 | 判定基準 | 結果 |
|---|---|---|---|
| lake at rest | 凹凸地形上の静水 | 水位が厳密に不変 | 合格 (1e-12) |
| 正値性・保存 | 凹凸地形に300 mm/h | $h\ge0$, 収支誤差 | 合格 (<1e-12) |
| 傾斜平面 | kinematic wave 解析解（上昇部） | 誤差 < 5% of $q_{eq}$ | 合格（両スキーム） |
| V字流域 | di Giammarco et al. (1996) | 平衡流量 4.86 m³/s ±1%, 減水部単調 | 合格（両スキーム） |
| dt収束 | CFL・dt_max を半減 | 差 < 2% | 合格（両スキーム） |
| スキーム比較 | inertial vs diffusive | 差 < 3% | 合格 |
| Green–Ampt | 湛水浸透の陰的解析解 | 相対誤差 < 1e-6 | 合格 |
| 地中流のみ | 透水量係数 > 降雨×斜面長 | 地表流ゼロ、平衡流出＝降雨 | 合格 |
| 堤防 | 低堤防→氾濫、高堤防→氾濫なし | 浸水深・流下量 | 合格 |
| 本間公式 | 完全/もぐり越流の連続性 | 差 < 1% | 合格 |
