# 14. 1K-RRI と施策・不確実性の見直し（モデル改訂 11.12）

1 km 格子のモデルを、通常の RRI から 1K-RRI（菅原・佐山・山田・山本 2024）に置き換えました。あわせて、施策の効果と不確実性の扱いも見直しました。以前の結果（探索 v2〜v4、DAPP 11.9〜11.11）はすべて残しています。古い 1 km の RRI モデルに戻すには `workflow.K1_ENABLED = False` とします。古いキャッシュも残っています。

## 14.1 1K-RRI（`rri_sim/k1rri.py`）

出典：菅原快斗・佐山敬洋・山田真史・山本浩大（2024）「広域かつ高速な降雨流出氾濫計算のためのマクロスケール RRI モデルの開発」土木学会論文集 80(16), 23-16125。

**構造**
- 1 km の各セルは、山地（面積 A_s、平均勾配 i_s）、平野（面積 A_f = セル面積 − A_s、平均勾配 i_f、標高 z_f）、河道を持ちます。
- 河道はすべてのセルにあります。

**論文の式**

| | 式 |
|---|---|
| 山地 (1) | A_s dh_s/dt = −q_s l_s + r A_s。q_s は飽和・不飽和の流量流積関係（立川ら 2004）で、勾配は i_s。山地は片側から河道へ流れ込む |
| 長さ (2) | l_s = A_s/(A_s+A_f)·l_r、l_r = l = √(ΔxΔy)、l_f = l_r − l_s |
| 平野 (3) | A_f dh_f/dt = Q_xy − 2 q_f l_f + 2 q_rf l_f − v_i A_f + r A_f |

平野の式の各項：
- Q_xy：周囲 8 方向の平野との diffusive wave。セルを「平均長さ l、水深 h_f、標高 z_f」の格子とみなして計算します。
- q_f：勾配 i_f の kinematic wave。河道の状態に関係なく河道へ入ります。
- q_rf：河道の水位が平野の水深 h_f と堤防高を超えたときの越流（本間の式）です。
- v_i：Green-Ampt の浸透です。

**河道**
- 流向は最大集水河道追跡法（中継領域つき、舛谷ら 2006）で決めます。
- 幅 w、深さ d、堤防高 h_b、標高 z_f は代表セル（中継領域を除いて集水面積が最大の細かいセル）の値です。
- 河床は z_f − d です。
- 集水面積 16 km² 以下の河道から、それより大きい河道への合流は kinematic wave で流します（背水を考えない）。

**土地利用**
- 山地と平野のそれぞれで最頻の土地利用を使います。

**作り方**
- 250 m モデル（`domain_abukuma_whole_250_*`）を 4×4 でまとめます。論文は 150 m の JRRI を 6×6 でまとめています。

**論文にないための仮定**（`k1rri.ASSUMPTIONS`）

| 項目 | 仮定 |
|---|---|
| 山地と平野の区別 | 250 m セルの土地利用が森林なら山地、それ以外は平野 |
| 中継領域 | 4×4 の区画の四隅の 1 セル |
| 隣接しない区画に達する経路 | 経路が最初に入った隣の区画を下流とする（流域で 198/5,719 セル） |
| 斜め方向の流下幅 | ΔxΔy / 距離 |
| 平野の kinematic wave | q_f = (1/n)(h_f − d_a − s_d)^{5/3} i_f^{1/2}（Manning 型） |
| 平均勾配 | 250 m DEM（未補正）の勾配の大きさの平均（下限 1e-4） |
| 流域界のセル | 流域内の面積だけを A_s, A_f とし、河道長 l_r も流域内の面積に比例させる |
| 河道でない代表セル | 250 m モデルと同じ河道断面式。堤防なし（3,889 セル） |
| 平野での施策 | 排水ポンプは、下流で最初に 16 km² を超える河道へ汲み上げる。田んぼダム・貯留施設の放流はそのセルの河道へ |
| 被害 | 平野の水深 h_f（標高 z_f が基準）を使う。建物・農地の標高分布は z_f からの差。被害の傾斜区分には i_f を使う |
| 河道の計算法 | 局所慣性式（下記）。論文は diffusive wave |

**河道の計算法を変えた理由**
- 論文と同じ diffusive wave にすると、陽解法の安定条件（dt ≤ V_eq/|Q|）のため、洪水中の時間刻みが数秒まで小さくなります。
- そこで局所慣性式（Bates et al. 2010）を使います。定常解は同じマニング式です。
- 平野の Q_xy は diffusive wave のままです。
- `workflow.K1_RIVER_SCHEME = "diffusive"` にすれば論文の方式に戻ります。

**確認（2019 年台風19号、流域 5,489.6 km²、5,719 セル、kinematic 合流 1,187 か所）**
- 計算時間は 26 s です（250 m モデルは 360 s）。質量保存の誤差は 6e-15 です。

- 被害額は約 5,250 億円、浸水面積は 164 km² です。
  - 250 m モデルは 7,452 億円・374 km²、500 m は 3,389 億円、旧 1 km の RRI は 756 億円でした（docs/08）。

## 14.2 施策と効果

- 効果係数（堤防・遊水地・田んぼダム・森林化・嵩上げ）はすべて削除しました。施策は物理パラメータどおりに計算します。
  - 探索 v5 は不確実性に効果係数を持ちません。
  - v4 以前の代理モデルは、保存した設定どおり効果係数を掛けます（再現のため）。
- 森林化（農地への植林）は 1K-RRI では扱いません。山地・平野の面積が変わってしまうためです。
- 代わりに森林整備（`forest_mgmt`）を使います。
  - 既存の山地の森林の物理パラメータを変えます。有効間隙率 γ_a, γ_m を `FOREST_MGMT_DA_GAIN` = 20% 増やします（仮定）。
  - 土層厚は変えません。
  - 地域ごとに 1 変数で、実施率は 0〜100% です。
- 実施の進み方：
  - 住宅の嵩上げ・移転、排水ポンプ、公共貯留、各戸貯留、制度的施策、田んぼダム、森林整備は、施工・普及の期間中に効果が 0→100% に線形に増えます（`sim.vec`）。
  - 堤防・遊水地は、完成時に一度に効きます。

## 14.3 将来の不確実性（`roadmap/world.py`）

- 削除したもの：
  - 気候が想定から外れ始める年
  - 資産の変化が始まる年。資産は 2020 年から線形に変わるとしました。
  - 効果係数のグループ
  - 観測誤差
- 真の気候：
  - 各世界は 2100 年の降雨倍率 X_r と海面上昇 X_s の真値を持ちます。
  - 真の経路は、降雨が 1 + (X_r − 1) g(t)、海面が X_s g(t) です。
  - g は 2050 年に降雨 0.6、海面 0.39 で、その間は線形です（`climate.path_2050`、仮定）。
- 予測（学習、`world.Forecast`）：
  - 事前分布は N(μ0, σ0²) です。μ0 は計画時の想定（×1.10・0.38 m）、σ0 は真値の範囲の (上限 − 下限)/√12 です。
  - 情報は dY = X dt + κ^{-1/2} dW の形で連続的に入ります。W は世界ごとのブラウン運動です。
  - 予測値は m_t = (μ0/σ0² + κ Y_t)/(1/σ0² + κ(t − t0))、予測の標準偏差は s_t = (1/σ0² + κ(t − t0))^{-1/2} です。
  - κ は、s_t が半分になる年（`forecast_half_year`：標準 2060、範囲 2040〜2090、仮定）から決めます。
  - 意思決定に使うのは (m_t, s_t) だけです。物理計算には真の経路を使います。
  - t から h 年後の予測は N(m_t, s_t² − s_{t+h}²) に従います（事前事後解析、`spread_later`）。

## 14.4 便益：発生頻度に基づく年平均被害額（`rri_sim/frequency.py`）

施策の便益は、代表洪水 1 回分の被害ではなく、発生頻度を踏まえた年平均被害額の減少で評価します（治水経済調査マニュアルの年平均被害軽減期待額）。

**年平均被害額**
- 確率規模 T = 1/2, 1/5, 1/10, 1/20, 1/30, 1/50, 1/100, 1/150, 1/200 の洪水の被害額 D_T から、次の式で求めます。
  - E = Σ (D_i + D_{i+1})/2 × (1/T_i − 1/T_{i+1})
- 1/2 より小さい洪水と、1/200 より大きい洪水は数えません。

**確率規模 T の洪水の作り方**
- 代表洪水（2019 年台風19号、1/100 とみなす）の雨量に、比 r(T) と気候の降雨倍率を掛けます（引き伸ばし）。
- r(T) は、流域内のアメダス 11 地点の年最大日降水量（43〜49 年分）から求めました。
  - 地点ごとに L 積率法で Gumbel 分布を当てはめ、r(T) = x_T / x_100 の中央値をとります。
  - 地点間の差は小さいです（1/10 で 0.63〜0.70）。

| T | 1/2 | 1/5 | 1/10 | 1/20 | 1/30 | 1/50 | 1/100 | 1/150 | 1/200 |
|---|---|---|---|---|---|---|---|---|---|
| r(T) | 0.41 | 0.57 | 0.67 | 0.77 | 0.83 | 0.90 | 1.00 | 1.06 | 1.10 |

**仮定**
- 代表洪水を 1/100 とみなす（以前と同じ）。
- 確率規模ごとの洪水は、雨の降り方（時間・空間の分布）が代表洪水と同じとする。
- 地点の日雨量の比で、流域雨量の比を代用する（面積による雨量の低減と、継続時間の違いは考えない）。
- 気候変動は、すべての確率規模に同じ倍率で効くとする。

**代理モデル（探索 v6、`data/processed/explore/run_v6.py`）**
- v5（降雨倍率 1.0〜1.3）の学習点 477 点に、次の点を加えて学習し直しました。
  - 降雨倍率 0.35〜1.5 の点 160 点（施策も変える）
  - 対策なしの点 40 点
- 検証用の点は 30 点です。

**Coverage との関係**
- Coverage（目標を満たすシナリオの割合）は、これまでどおり代表洪水（1/100）の被害額・浸水人口で判定します。
